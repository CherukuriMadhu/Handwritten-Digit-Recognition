# Handwritten Digit Recognition using MNIST

## 📌 Project Overview
This project implements a **handwritten digit classification system** using the **MNIST dataset**, which consists of grayscale images of handwritten digits (0–9).  
The goal is to accurately classify digits using a **machine learning approach (Logistic Regression)** and evaluate the model’s performance on unseen data.

This project demonstrates hands-on experience with **data preprocessing, model training, evaluation, and Python-based workflows**.

---

## 🧠 Problem Statement
Given a 28×28 grayscale image of a handwritten digit, predict the correct digit (0–9).

---

## 📊 Dataset
- **Dataset:** MNIST Handwritten Digits
- **Total Images:** 70,000  
  - Training: 60,000  
  - Testing: 10,000
- **Image Size:** 28×28 pixels
- **Classes:** 10 (digits 0–9)

---

## 🛠️ Technologies Used
- **Programming Language:** Python  
- **Libraries & Frameworks:**
  - NumPy
  - Scikit-learn
  - Matplotlib (for visualization)

---

## ⚙️ Approach & Methodology
1. **Data Preprocessing**
   - Normalized pixel values
   - Reshaped images and split data into training and testing sets

2. **Model Implementation**
   - Implemented a **Logistic Regression model** using Scikit-learn
   - Used standard optimization and classification techniques

3. **Model Training**
   - Trained the model on training data
   - Tuned basic hyperparameters for improved accuracy

4. **Evaluation**
   - Tested the model on unseen data
   - Evaluated using standard classification metrics

---

## 📈 Evaluation Metrics
- Accuracy  
- Precision  
- Recall  
- F1-Score  
- Confusion Matrix  

The model achieved strong performance and demonstrated effective classification capability on the test dataset.

---

## 🚀 Results
- Successfully classified handwritten digits with reliable accuracy
- Demonstrated robust performance across all digit classes
